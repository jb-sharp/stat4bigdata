# Statistica per i Big Data Economico-Aziendali
Repository per i materiali didattici delle Esercitazioni dell'anno accademico 2024/2025.

- Lezione 1
    - Introduzione
    - Tipi di dato (numerici, booleani e stringhe)
    - Costanti e variabili
- Lezione 2
    - Strutture dati (liste, tuple, insiemi e dizionari)
    - Moduli (os) e files
- Lezione 3
    - Booleani e operatori logigi
    - Costrutti if, if-else, if-elif-else
- Lezione 4
    - Cicli for e while,
    - Istruzioni break e continue
    - List comprehension
    - Funzioni range e enumerate
- Lezione 5
    - Funzioni
    - Visibilità delle variabili
    - Ricorsione
- Lezione 6
    - Classi e oggetti
    - Ereditarietà
